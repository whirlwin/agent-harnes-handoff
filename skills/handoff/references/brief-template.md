# Task handoff

## Goal and latest user request
Include acceptance criteria and corrections to earlier requests.

## Constraints and approvals
Record scope, user preferences, safety constraints, and actions awaiting approval.
The receiving harness must read its own current repository instructions.

## Completed work
List relevant paths, edits, commits or PR links. Distinguish pre-existing changes
from changes made in this session. Do not claim unfinished work is complete.

## Decisions
Summarize decisions, rationale, and rejected approaches useful to continuing work.

## Verification
Exact commands and observed outcomes, including failures and tests not yet run.

## Blockers, running jobs, and unknowns
Include job identifiers or output locations only when known. State whether the
source agent has stopped writing and whether the target must wait.

## Next steps
An ordered list, starting with the next concrete authorized action.

## Relevant references
Useful files and links; no credentials, raw personal data, or full transcripts.
